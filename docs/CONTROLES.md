# Controles — Clareira dos Goblins

Os comandos documentados abaixo correspondem às atualizações recentes. Confira a implementação exata em `Projeto-Godot/main.gd`.

| Comando | Ação |
|---|---|
| E | Inventário |
| Esc | Menu |
| Botão direito na bancada | Acessar fabricação |
| T (com parede fechada selecionada) | Alternar peça entre vertical e piso/teto |
| Page Up / Page Down | Alterar nível do pavimento |
| Botão esquerdo (modo construção) | Posicionar a peça |

Hotbar: nove espaços, com itens coletados preferencialmente nos espaços livres. O comportamento depende da versão instalada.

Consulte o jogo para outros comandos (andar, atacar, interagir etc.); não são definidos aqui sem confirmação no código local.
